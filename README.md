# JTGeats – Frontend Home Assignment

A pixel-perfect, responsive static website for a home-cooked food delivery service built using **HTML5, CSS3, and Vanilla JavaScript**.

This project was developed as part of the **Josh Technology Group (JTG) Frontend Assignment**, with a strong focus on semantic HTML, clean architecture, performance optimization, accessibility, and cross-browser compatibility.

# Features

## Component-Based Architecture

Each section is maintained independently and injected dynamically using `fetch()`.

## Interactive Carousel

* Previous/Next buttons
* Auto-slide (5 seconds)
* Dot indicators
* Keyboard navigation
* Drag and swipe support

## Quantity Counter

The Add button transforms into:

```text
− 1 +
```

Quantity updates dynamically.

## Accessible Modal

* Escape key support
* Overlay click to close
* Focus trapping

## Video Controls

* Custom play button
* Auto-hide button while playing

## Responsive Design

Optimized for:

* 1440px Desktop
* 1024px Laptop
* 768px Tablet
* 480px Mobile

## Cross-Browser Compatibility

Tested on:

* Google Chrome
* Mozilla Firefox
* Safari

# Pixel Perfect Implementation

The UI was matched against the Figma design using the PerfectPixel Chrome extension.

Configuration:

```text
Scale: 1.0
X Offset: 0
Y Offset: 0
```

At a 1440px viewport, the implementation closely matches the provided mockup.
